LOCAL SETUP GUIDE

Get Qwen3-VL running
in about 10 minutes.

Trefelle's local option talks directly to Ollama or LM Studio on your own machine—free, private, and no account needed. Pick whichever one you use and follow the steps in order. Jump to Ollama, LM Studio, or troubleshooting.

BEFORE YOU START

What your machine needs.

HARDWARE

Enough room to run it

  • ~6 GB free storage for the model download
  • 16 GB+ RAM recommended
  • A GPU makes it noticeably faster, but isn't required
WHY THIS ONE MODEL

Qwen3-VL specifically

Trefelle only supports Qwen3-VL locally right now because it's one of the few open models with both real reasoning and vision built in—vision is what lets it read a resume file you attach directly, the same way Claude Sonnet does on the BYOK side.

OPTION A

Set up with Ollama

01

Install Ollama

Download it from ollama.com/download and install it like any other app. It runs quietly in the background (look for its icon in your system tray / menu bar).

02

Pull Qwen3-VL

Open a terminal and run:

ollama pull qwen3-vl

This downloads ~6 GB. Grab a coffee.

03

Allow Trefelle to reach it

By default, Ollama only accepts requests from apps on your own machine at localhost—it blocks requests coming from a website like Trefelle unless you explicitly allow it. Set the OLLAMA_ORIGINS environment variable, then restart Ollama.

Windows — PowerShell:

[Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS", "*", "User")

Then quit Ollama from the system tray (right-click its icon → Quit) and reopen it from the Start Menu so it picks up the change.

macOS — Terminal:

launchctl setenv OLLAMA_ORIGINS "*"

Then quit and reopen Ollama from the menu bar.

Linux (systemd service) — Terminal:

sudo systemctl edit ollama.service

Add these two lines in the editor that opens, then save and exit: 

[Service]
Environment="OLLAMA_ORIGINS=*"

Then restart the service:

sudo systemctl daemon-reload
sudo systemctl restart ollama

Running ollama serve manually in a terminal instead? Just set OLLAMA_ORIGINS=* in that same terminal before starting it.

04

Connect it in Trefelle

In the workspace setup, choose Run it locally, confirm the address http://localhost:11434, and Trefelle will find Qwen3-VL automatically.

OPTION B

Set up with LM Studio

01

Install LM Studio

Download it from lmstudio.ai and install it.

02

Download Qwen3-VL

In LM Studio, open the search/discover tab, search for Qwen3-VL, and download an 8B (or similar) instruct variant.

03

Start the local server with CORS on

Open the Developer tab, load the Qwen3-VL model, and in the server settings turn on Enable CORS—it's off by default, and without it your browser can't reach the server from a website. Then toggle Start server.

Prefer the command line? lms server start --cors does the same thing.

04

Connect it in Trefelle

In the workspace setup, choose Run it locally, confirm the address http://localhost:1234, and Trefelle will find Qwen3-VL automatically.

TROUBLESHOOTING

What each error actually means.

“COULDN’T REACH YOUR SERVER”

It's not running

Ollama or LM Studio isn't open, or the local server inside LM Studio hasn't been started. Open the app and check.

“QWEN3-VL ISN’T AVAILABLE”

It's running, but not pulled

The server responded, but no model matching Qwen3-VL was found on it. Run the pull/download step above, then click Check again.

SILENT FAILURE, NEVER FINDS IT

It's blocked by CORS

The model is there, but your browser's request is being silently rejected before it even reaches the app. This is the OLLAMA_ORIGINS / Enable CORS step above—it's the most commonly missed one.
