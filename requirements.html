AI MENTOR · FOR NOW

Only two models—
on purpose.

Trefelle is unfunded, so there's no hosted AI mentor running on our bill yet. Rather than opening the mentor up to every provider and model—where results, judgment, and quality would quietly vary person to person—it currently runs on exactly two options we've verified handle the assessment (including attached resume files) reliably and consistently.

WHO THIS IS FOR, HONESTLY

Right now, this is built for
the technical and the curious.

We're two people building this on the side—we don't have the funding to run a hosted AI model for everyone, which is the actual reason there's setup involved at all. Today, this is realistically for people who want to support a small, early-stage project; who are curious what a real professional workspace needs to be wired up and configured; and who are comfortable enough with tech to manage an API key or set up a local LLM like Ollama or LM Studio.

If that's not you yet, that's completely fine—you're not the problem, the setup is. A hosted, zero-setup mentor is the actual long-term plan; this is just what's realistic before it exists.

TWO WAYS TO RUN IT

Pick based on your
hardware, not ours.

01

Bring your own key — Claude Sonnet

Connect an Anthropic API key. Requests go straight from your browser to Anthropic—we never see the key or the bill.

02

Run it locally — Qwen3-VL

If you run Ollama, pull Qwen3-VL and Trefelle talks to it directly—free, private, and the only local model currently supported.

SYSTEM REQUIREMENTS

What each option actually needs from your machine.

OPTION 01

Bring your own key — Claude Sonnet

Best answer quality. Costs you per use, billed by Anthropic directly.

  • An API key from an Anthropic account with API access
  • Any modern browser, any device
  • An internet connection
  • A card on file with Anthropic for usage billing
Setup: ~2 minutes
OPTION 02

Run it locally — Qwen3-VL

Free, fast, and fully private—if you're set up to run it.

  • Ollama or LM Studio installed and running
  • Qwen3-VL pulled or downloaded
  • 16 GB+ RAM recommended for comfortable use
  • CORS allowed so your browser can reach it (covered in the guide)
Setup: for existing Ollama/LM Studio users
